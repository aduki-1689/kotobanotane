Google Apps Script 接続手順
  1. Googleスプレッドシートを作成し、「拡張機能」→「Apps Script」を開きます。
  2. プロジェクト内の google-apps-script/Code.gs を貼り付け、スクリプトプロパティ SPREADSHEET_ID にシートIDを設定します。
  3. 公開運用では SHARED_SECRET を未設定にしないでください。ただし、ブラウザに入力して利用者へ共有したシークレットは利用者から確認できます。
  4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で実行ユーザーを自分、アクセスできるユーザーを用途に合わせて設定してデプロイします。
  5. 発行されたURLと同じシークレットを上の設定欄に入力し、投稿候補を選んで保存します。

この送信方式ではブラウザから完了レスポンスを読めない場合があります。スプレッドシートに行が追加されたことを確認してください。公開ページは誰でも利用でき、入力内容は利用者のブラウザで分析されます。保存時には選択した投稿データがApps Scriptへ送信されます。共有シークレットだけで公開利用者からの書き込みを安全に制限することはできません。

順位は具体性・記事との結びつき・独自性・読者への価値などをもとにした簡易評価です。内容を確認して編集してください。
